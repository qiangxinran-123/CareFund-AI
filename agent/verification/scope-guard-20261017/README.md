## 修复行为

`AgentService.extract` 对模型新增的事实字段和所有返回追问的字段执行范围检查。范围沿用已测试抽取提示词中的开发清单，集中定义于 [extract_policy.py](../../extract_policy.py)，不将其当作团队已确定的必填业务规则。

新事实可用患者关系、病情、已支付医疗费、后续预估治疗费、治疗记录日期及当前城市六个字段。追问另允许 `documents.diagnosis_proof`，该字段不能用于新增事实。

- 范围外字段使整个结果抛出固定的 `AgentError`，不静默删字段、不返回部分成功、不自动重试。
- 输入中已有的事实可以保留历史字段，但必须以相同 ID 完整原样返回；新 ID 不能借用旧事实的范围外字段绕过检查。
- 错误文字不包含模型字段值、患者正文或密钥。
- 草稿继续使用既有确认、问题 ID、事实冲突及固定正文门槛。

这能阻止范围外结果被 A 当作成功结果交给 B；它不能保证模型以后不再生成范围外字段。B 接入新版 A 时需处理 `AgentError`，不得继续保存部分结果或据此导出。
