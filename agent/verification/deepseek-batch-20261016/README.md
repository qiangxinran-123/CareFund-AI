## 发现的实际问题

`extract_0042` 的输入只给出筹款目标和已募集金额，未给出病情或医疗费用。模型没有把筹款金额误当作医疗费，但生成了当前提示词清单以外的新字段：

- `fundraising.target_amount`：筹款目标 30000 元；
- `fundraising.raised_amount`：已募集 4000 元。

本轮已测试提示词明确要求“暂不抽取超出以上范围的新字段”，范围外信息应在 warnings 中说明。当前 Schema 只检查字段格式，`AgentService` 没有程序化的字段范围门槛，因此自动检查仍显示通过。D 能接收这些事实也不表示已满足 A 的提示词规则。

问题证据在 [extract_0042.response.json](extract_0042.response.json)，原补充评测判据在 [review_checks.py](review_checks.py)。本批生成时尚无运行时字段范围检查；后续已增加 Python 门槛拦截，原有事实完整原样保留。共享字段契约仍保留。后续原输入已在独立新报告中回归通过，但不能保证模型不会再次生成范围外字段；本批旧错误响应不改写。
