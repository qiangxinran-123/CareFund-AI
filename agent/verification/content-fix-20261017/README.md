提醒和追问来自代码中的固定句子，不把模型措辞改成另一段模型猜测。未知信息可以保留，用户可以拒绝继续；无团队必填依据时 required 为 false。既有事实、证据 ID、确认状态和版本不变。用户更正仍需另建候选，不能覆盖历史。

`last_extract_raw_response` 在 service 内存保留通过边界检查的原模型响应，`last_extract_presentation_report` 记录版本、指纹和规则等无正文元数据。两者不是共享契约字段，不加入返回 JSON；失败时清空，避免沿用上次状态。B 每次请求创建独立的 service/runner，按受控存储规则留审计；不将内存原响应直接展示或写入普通日志。
