# 内容复核与交付前检查（2026-10-17）

本轮执行用户指定的两步：复核 60 条不同真实来源疾病字段的保存结果；复核 27 个已有虚构复杂场景。没有发送新患者资料，没有新增生成调用，也没有恢复全量测试。

## 如何复核

先冻结当前已暂停批次。1,350 次调用中，1,338 次部分检查通过、11 次失败、1 次需上下文复核。该上下文标记此前核对为否定性免责声明，原账本仍保留；一条网络失败此前恢复到原响应并离线通过，原失败也保留。这两项没有拿来篡改直接通过数。

从可读保存响应中的 757 个不同字段中，按疑似 4、非字前缀或否定字面匹配 13、分期 8、多项 10、长字段 8、口语歧义 2、固定种子补覆盖 15 选择 60 条。这里的“非”多数是病名组成部分，不能把这组称为 13 条真正否定诊断；真正已排除场景另有虚构 S004。只从已返回的结果中抽样，不包含网络失败，且不是全数据随机样本。

本助手逐条读取输入、事实、问题及警告，对照是否保留原文项目、部位、分型、分期、疑似/否定及未知费用。另由程序验证原请求和响应指纹、A 契约边界、来源及 pending/未确认状态。**这不是人工临床专家标注，不证明原诊断真实，也不是医疗准确率。**

复杂案例来自此前 expanded 和 currency-wording 两批：21 抽取、6 草稿，包括中文大金额、模糊金额、筹款金额隔离、外币、已排除、未确诊、材料冲突、部分日期、长输入、已有事实、草稿更正来源、引用和指令。S020 只验证草稿侧更正来源；完整用户更正事务没有真实联调，本轮用独立离线生命周期测试补充边界覆盖。

## 发现

所选 87 份输出的**事实正文**未观察到原文内容被添加或漏掉；这不代表 87 份全面合格。真实来源的 60 份中，16 份有以下问题或体验改进点（类别重叠）：

| 类别 | 条数 | 脱敏复核 ID | 处理 |
|---|---:|---|---|
| 警告给出来源未含的替代拼写 | 7 | R001、R019、R028、R032、R037、R040、R042 | 原事实保留；建议只请用户核对原文，不提示模型猜测的“正确”写法 |
| 警告推测并列病情的关联 | 1 | R026 | 输入没有说明该关联；即使使用“可能”，仍不应由模型补充 |
| 问题没有优先澄清明确歧义 | 7 | R001、R002、R003、R028、R041、R044、R060 | 不确定性留在事实和警告中，但通用问题占满名额，针对性不足 |
| 缺信息但问题为空 | 3 | R010、R034、R038 | 当前 Schema 允许，属于体验改进，不当作格式失败或新必填要求 |

虚构复杂案例保留 4 个事项：

- S014：逐字草稿引述了源事实里的无效攻击指令；没有新增费用或审核通过结论，但仍不适合直接发布。
- S015：费用冲突两值和来源正确保留；问题预设“用户记错或材料更新”，应改成中性核对费用范围、时间及依据。
- S018：历史警告无依据地声称平台常用人民币。S022 是后续相同请求的回归，该措辞未再出现；历史问题仍保留，不把两次混成同一版本的全通过。
- S026：正确把币种规则归因给用户猜测，但重复要求确认输入已经明确的 USD 币种。

已经写好 [提示词修订候选](../../prompts/extract-content-v5-append-CANDIDATE.md)及 8 个虚构回归请求 `candidate-test-plan.json`，**尚未发布、尚未真实调用验证**。本轮没有静默删除或改写警告来“修好”历史输出。正式 DSL 仍是已导出核对版本。

## 文件和复现

- `selection.json`：选择方法、冻结进度及本地证据指纹。
- `review-results.json`：60+27 条逐条脱敏结论，无真实疾病正文。结论为本助手观察，不是专家标签。
- `synthetic-replay.json`：仅 27 组虚构输入和历史输出，可以发队友。
- `replay.py`：在项目根目录运行，验证上述虚构结果的指纹、当前 A 门槛和有限原判据；显式禁止建立网络连接。
- `review_notes.py`：本助手逐条结论的源码；`prepare_review.py`、`finalize_review.py` 是原机的取证脚本，依赖未交付的 `.local/`，不能在队友机器上伪造真实证据重建。
- `local-checks.json`：本轮 A 89 项、契约 10 项、批量控制 20 项及虚构回放的离线检查记录。

真实输入、响应和原 CSV 留在原机被 Git 忽略的 `.local/` 或原数据位置。队友可以复验虚构结果及代码测试，不能仅凭脱敏报告独立重做真实文本逐条比较。哈希保证记录绑定，不能证明诊断真值或审核者独立性。

目前测试量足以进入小组接口接入和有针对性的改进阶段；没有证据支持总体临床准确率、完整 OCR、B/D 事务、用户确认或最终导出验收。继续堆相似疾病短句无法代替这些检查。
