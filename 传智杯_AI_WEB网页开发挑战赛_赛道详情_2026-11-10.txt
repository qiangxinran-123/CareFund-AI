======================================================================
一、赛道基本信息
======================================================================

赛道名称：AI WEB 网页开发挑战赛
赛道类型：团队赛
赛道状态：报名中
报名时间：2026-07-29 至 2026-11-18

赛道主题：
“智启未来：AI 驱动的 Web 应用创新挑战”

赛道定位：
面向全国高等院校在校学生，推动人工智能技术与 Web 应用开发深度融合，
培养具备 AI 工程化能力的新一代开发者。参赛作品应以现代前端框架为基础，
综合运用大语言模型（LLM）、AI Agent、RAG、 多模态 AI 等技术，构建具有
实际应用价值且交互体验良好的 AI 原生 Web 应用。

核心考察能力：
1. 前端工程能力：现代前端框架、组件化、状态管理、性能优化。
2. AI 技术集成能力：高质量集成大模型 API 和 AI 交互能力。
3. 创新思维能力：发现真实需求，提出创新的 AI + Web 解决方案。
4. 用户体验设计能力：将 AI 能力转化为流畅、直觉的 UI/UX。

赛事采用“院校赛—省赛—国赛”三级赛制。

======================================================================
二、命题范围与选题要求
======================================================================

参赛作品必须是基于 AI 技术的 Web 应用。可从推荐方向中选择，也可自拟与
AI Web 应用相关的选题。作品应体现 AI 技术的深度应用，而非简单的 API 调用。

推荐方向：
1. AI Agent 智能助手
   具备自主规划、工具调用、多轮对话能力，如个人助手、智能客服、自动化工作流。

2. RAG 知识问答系统
   使用向量数据库和检索增强生成，如学术助手、企业知识管理平台。

3. 多模态 AI 创意平台
   整合文本、图像、语音、视频等能力，如 AI 设计、视频编辑、故事创作。

4. AI 协同办公工具
   如 AI 写作、会议纪要、项目管理、智能文档分析。

5. AI 教育与学习平台
   如 AI 辅导教师、智能出题、自适应学习路径、编程教学助手。

6. AI 健康与生活服务
   如 AI 营养分析、心理健康对话、智能运动指导。

7. AI 代码开发辅助
   如代码审查 Agent、API 文档生成、架构设计、自动化测试生成。

8. AI 数据分析与可视化
   通过自然语言完成数据查询、分析与可视化。

9. AI 安全与内容治理
   如内容安全、隐私保护、AI 生成内容识别，体现负责任 AI。

10. AI 社交与社区应用
    如 AI 匹配推荐、社区运营助手、兴趣图谱。

选题硬性要求：
1. 作品必须原创，严禁抄袭或直接包装开源项目参赛。
2. 必须以 Web 应用形态呈现，包括 PC Web 或移动 Web。
3. 必须深度集成 AI，AI 功能应为应用核心而非附属功能。

鼓励项：
1. 关注社会价值，解决真实问题，具备落地潜力。
2. 探索创新的 AI 应用方式，不简单复刻已有产品。

六、评分标准
======================================================================

总览：
1. AI 技术深度：35%
2. 创新性：25%
3. 前端工程质量：10%
4. 实用性：10%
5. 用户体验：10%
6. 社会价值与商业潜力：10%

（一）AI 技术深度：35%

1. 大模型集成质量：8%
   模型选择是否合理；LLM 集成质量；Prompt 设计；输出稳定性与可控性。

2. Agent / 工作流设计：8%
   是否实现 Agent 或复杂 AI 工作流；是否具备规划、工具调用、自主决策。

3. RAG 技术应用：6%
   是否实现 RAG；检索策略是否合理；生成质量是否因检索增强而提升。

4. 多模态能力：5%
   是否融合文本、图像、语音、视频等多种模态，融合是否自然。

5. AI 安全与可控性：4%
   是否考虑输出安全、可解释性、内容过滤和兜底机制。

6. MCP / 工具集成：4%
   是否通过 MCP 或 Function Calling 连接外部工具和数据源。

（二）创新性：25%

1. 选题创新：10%
   是否发现独特场景或未满足需求。
2. 技术方案创新：8%
   AI 技术组合是否有新意，方案是否独特。
3. 交互模式创新：7%
   人机交互是否创新，是否超越传统应用体验。

（三）前端工程质量：10%

1. 前端代码质量：4%
   TypeScript 使用规范，组件清晰，可维护，无明显 Bug。
2. 组件化与架构：3%
   组件划分、状态管理、模块解耦和复用性。
3. 前端性能优化：3%
   首屏速度、渲染性能、懒加载、代码分割和缓存策略。

（四）实用性：10%

1. 场景真实性：5%
2. 解决方案有效性：5%

（五）用户体验：10%

1. UI 设计与视觉表现：4%
2. 前端交互体验：3%
3. AI 交互体验：3%
   包括流式输出、AI 思考状态可视化、错误边界处理。

（六）社会价值与商业潜力：10%

1. 社会价值：5%
2. 商业潜力：5%

评分方式：
1. 各维度采用百分制评分，再按权重计算总分。
2. 每件作品由不少于 3 位专家独立评分，取平均分。
3. 决赛阶段增加现场答辩评分，占决赛总分 30%。

七、技术环境与官方建议
======================================================================

技术选型不强制，但作品必须基于主流前端 Web 技术体系。

推荐前端框架：
1. React + Next.js 14+
2. Vue 3 + Nuxt 3
3. Svelte 5 + SvelteKit
4. React + Vite
5. Astro

推荐 UI 与样式：
Tailwind CSS、shadcn/ui、Ant Design、Element Plus、Framer Motion、GSAP、
Three.js、React Three Fiber。

推荐前端 AI 集成技术：
Vercel AI SDK、LangChain.js、Transformers.js、WebGPU、ONNX Runtime Web、
Web Speech API、MediaPipe。

推荐模型/API：
1. 大语言模型：OpenAI、Claude、Gemini、智谱、DeepSeek。
2. 多模态模型：GPT-4o、Gemini Pro Vision、通义千问 VL。
3. 图像生成：DALL·E 3、Stability AI。
4. 语音：Whisper、TTS。

推荐状态管理和数据层：
Zustand、Jotai、Pinia、TanStack Query、IndexedDB、LocalStorage、WebSocket、SSE。

开发工具建议：
1. AI 辅助编程：Cursor、GitHub Copilot、Windsurf。
2. UI 原型：Figma、v0.dev。
3. 组件开发：Storybook。
4. 版本控制：Git + GitHub/Gitee。
5. 包管理：pnpm、npm、yarn。
6. 代码规范：ESLint + Prettier + TypeScript。

特别说明：
1. 以前端 Web 应用为主要呈现形态，后端主要作为 AI 能力接入层。
2. 允许使用 AI 辅助编程，但参赛者必须能清晰解释所有代码逻辑。
3. 商用 AI API 费用由参赛者承担。
4. 鼓励浏览器端 AI 推理。
5. 涉及用户数据时必须遵守法律法规并做好隐私保护。
